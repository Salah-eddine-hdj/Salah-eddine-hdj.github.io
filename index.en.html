Experience

Internship at Jokkere

Territorial intelligence SaaS startup · 2 months

Jokkere develops a SaaS platform for territorial intelligence using public data (Insee, data.gouv, BANATIC).

  • Feasibility study of data sources

    Insee, data.gouv, BANATIC: identified indicators exploitable via direct REST APIs, and datasets available only as files (CSV, XLS) requiring a collection, validation, and aggregation pipeline before PostgreSQL integration.

  • New territorial indicators

    Integration in React, Spring Boot, and JPA, with comparison to a national baseline, using Insee data processed and cached on the backend.

  • Java ↔ TypeScript data contract

    Designed and deployed an explicit contract replacing ambiguous numeric values with typed statuses (ok / fallback / absent / error). Migrated to production with zero downtime via a temporary frontend/backend compatibility layer.

  • Characterization tests and refactoring

    Used JUnit, Cucumber, Vitest, and React Testing Library (186 tests) to secure two major refactors: reduced a React component from ~3000 to ~1100 lines, and replaced a monolithic backend class with 23 specialized service files (~2970 lines removed).

  • Content contribution module

    JavaScript, Supabase/PostgreSQL: JSONB data modeling, file management, and security via Row Level Security.
